# 使用说明

适用版本：数据集 `2026-10-21.1`。本文件只描述已经实现并验证过的功能。

## 1. 启动

需要 Python 3（`beautifulsoup4`、`lxml`，见 `requirements.txt`）。

```powershell
Set-Location 'D:\desk\1learn\OS\exercises\os-exercises'
.\scripts\start.ps1
```

脚本会先构建 `dist/`，再在 `http://127.0.0.1:8765/` 启动本地服务。

**不想折腾就用线上版**：<https://dou307.github.io/os-exercises/>
由 `.github/workflows/deploy-pages.yml` 在每次 push 到 `main` 时自动构建发布（先跑 `validate_dataset.py`，
不通过就不发布）。注意：**学习记录按 origin 隔离**——本地 8765 和线上的 `dou307.github.io` 是两套记录，
要用线上就得在线上做题，或者用首页的导出/导入搬运。

线上版是公开站点，内容包含上游无 LICENSE 的题库与教材插图，见 `THIRD_PARTY_NOTICE.md`；
想关掉见 `docs/来源说明.md`。

常用参数：

| 参数 | 作用 |
|---|---|
| `-Port 9000` | 换端口（注意：换端口等于换 origin，浏览器记录不会自动继承） |
| `-NoBuild` | 跳过构建，直接用现有 `dist/` |
| `-Open` | 启动后自动打开浏览器 |
| `-Lan` | 绑 `0.0.0.0`，同一 Wi-Fi 下的手机/平板用局域网地址访问 |

`-Lan` 会打印本机所有局域网地址，例如 `http://192.168.1.5:8765/`。它只对同网段开放，
适合家庭或宿舍内网；公共 Wi-Fi 下不要用。学习记录按 origin 隔离，换 IP 或端口不会自动继承。

**必须通过 HTTP 访问。** 直接双击 `dist/index.html` 会因浏览器对 `fetch` 的限制而加载不到数据。

## 2. 页面

| 页面 | 入口 | 内容 |
|---|---|---|
| 首页 | `#/` | 已作答/答对/答错统计、当前学习范围、学习记录导出导入、全部章节 |
| 章节 | 左侧目录 | 本章题量、核心/桥接/补充/待核对、题单 |
| 练习 | 章节页“开始核心练习” | 逐题作答，位置写在地址栏，刷新可恢复 |
| 单题 | 题单或搜索结果 | 单题查看，记录与题单共用 |
| 错题回顾 | 左侧目录 | 答错的题与自评“还需复习”的题，可重做 |
| 我的收藏 | 左侧目录、首页 | 手动收藏与答错自动收藏的题，可按章筛选、取消 |
| 搜索 | 顶部输入框 | 题干、章节名、原题号、题目 ID、知识点 ID |
| 原题库 | 左侧目录 | 上游 5 章原页面，公式已改为本地资源 |

## 3. 键盘

| 按键 | 作用 |
|---|---|
| `A`–`D` 或 `1`–`4` | 选择对应选项 |
| `Enter` | 提交答案 |
| `→` / `←` | 下一题 / 上一题 |
| `Tab` | 在选项、按钮之间移动，焦点有可见描边 |

在综合题的自答文本框里输入时，上述快捷键不会触发。

## 4. 判分规则

| 题型 | 行为 |
|---|---|
| 单选（`single_choice`） | 提交后自动判分，保存实际选项、首次结果与最近结果 |
| 多空/复合（`multi_blank`） | 不判分；展示原始选项块与答案，可自评 |
| 综合（`constructed_response`） | 可写自答草稿，看参考答案后自评“会做 / 还需复习” |
| 待核对（`reviewStatus = disputed`） | 保留原答案，标注不计分，记录不进对错统计 |

刷新后：已提交的题会恢复实际选项、对错标记与解析；未提交但已选中的题也会恢复选择。
“重做本题”会保留首次结果、累计次数与自答草稿，并清掉本轮的临时选择；重新提交后更新最近结果。
多空/综合题同一轮内修改自评不增加作答次数。

## 4.1 题号和收藏

- 题单各组按当前显示顺序连续编号；点进单题或进入练习后使用新题号，不显示来源题号和内部ID。
- 从带题型/作答状态筛选的题单点入时，编号沿用当前筛选结果，刷新也保留筛选条件。若该题后来不再符合筛选，回退为所属组的题号。
- 搜索、错题、收藏和首页继续入口沿用该题所属章节组的编号。练习导航的“第几/共几题”表示当前练习范围内的位置。
- 题卡右上点“☆ 收藏”可手动加入，再点“★ 已收藏”可取消；综合题和待核对题也可手动收藏。
- 自动判分答错时立即加入收藏。重做答对不会自动取消，需手动移除；自评“还需复习”继续进入错题回顾，不当作客观答错自动收藏。
- 左侧“我的收藏”按最近收藏时间排列，可按章节筛选并直接取消；章节题单也有“已收藏”筛选。
- 首次升级旧记录时，将当前仍被判错的题补入收藏；已经退出自动判分的争议历史不补入。手动取消后刷新不会恢复，但再次答错会重新收藏。

## 5. 学习记录

- 只写入 `os-exercises:v1` 这个键，不读写原站的 `os408-*` 记录。
- 记录按稳定题目 ID 保存，与页面顺序无关。
- 浏览器禁止本地存储时（隐私模式、站点设置），页面顶部会明确提示，作答只保留在内存中。
- 首页“导出记录”生成 JSON 备份；“导入记录”会先校验格式版本，再按题目 ID 合并，
  同一题保留 `lastAt` 较新的一份，未知 ID 跳过并计数，不会清空现有记录。
- 导入还校验作答字段、日期、次数和计分方式；任一已知题目记录损坏时整份拒绝，避免部分写入。
- 已学章节标记随备份导出并合并导入，旧版未含该字段的 v1 备份仍可使用；未知 schema 不自动转换。
- 收藏作为 v1 的可选字段一起导出/导入，保存收藏状态和独立修改时间；取消标记也保留，合并采用较新的修改，防止旧备份恢复已取消的收藏。
- 旧备份没有收藏字段时仍兼容：新导入的当前错题可补收藏，既有手动取消不被覆盖。收藏字段损坏同样整份拒绝，原记录保持不变。

## 6. 学习进度与“标记已学”

- 只有第 1 章 Introduction 是用户确认过的完成状态，写死在 `data/study-defaults.json`。
- 其他章节默认“进度未知”，题目归在“稍后再学”。
- 章节页的“标记本章已学完”只写本机存储（`ui.completedChapters`），标记后原“稍后”题进入桥接范围（核心 + 桥接练习入口），
  但**仍然显示“系统映射”徽标**——第 2～5 章只做了小节级知识点映射，答案没有逐题人工复核。
- 已确认的第 1 章不提供取消标记，避免误操作覆盖既有事实。

第一章题单按互斥口径显示：核心 40、桥接 1、补充 12、待核对 3。核心与桥接练习共 41 道，
待核对题单列不计分。顶部搜索支持完整题干、章节名与知识点，可按章节、题型、当前分层筛选；
超过 100 个结果会注明总量与当前显示上限。

## 6.1 徽标含义

| 徽标 | 含义 |
|---|---|
| 核心 / 桥接 | 第一章内按前置知识分层，核心可直接做，桥接会提示前置 |
| 补充 | 上游有题、但笔记第 1 章没有对应小节（批处理/实时类型、虚拟机） |
| 已核对 | 逐题核对过题干、选项、答案与解析（第一章 verified） |
| 已核对归属 | 逐题核对过归属与分层，答案未发现需要改判的问题 |
| 系统映射 | 按小节映射到知识点，答案未逐题人工复核（第 2～5 章） |
| 待核对 | 原答案有实质疑点，保留原文、不计分 |

## 7. 笔记跳转（可选）

默认关闭，界面不会硬编码任何 Obsidian 库名。启用方式：

```powershell
Copy-Item config.example.json config.local.json
```

编辑 `config.local.json`：

```json
{
  "notesRoot": "D:\\desk\\Obsidian\\1大三秋冬\\OS",
  "obsidianVault": "你的 Obsidian 库名称"
}
```

重新构建后，题目卡底部会出现“在笔记中打开 xxx.md”，链接形如
`obsidian://open?vault=<库名>&file=1-Introduction.md`。

`config.local.json` 已在 `.gitignore` 中，不会被提交。文件存在但 JSON 格式错误时，构建会打印警告并关闭该功能。

## 8. 常见问题

**页面显示“无法加载数据”**
没有通过 HTTP 访问，或没有先运行 `scripts/build.py`。

**公式显示成 `\(T\)` 这样的原始文本**
`dist/vendor/katex/` 缺失。重新运行 `scripts/build.py`。

**刷新后记录不见了**
先确认地址栏端口没变（origin 变了记录就不同）；再确认浏览器没有拦截本地存储（页面会有提示）。

**原题库页面里公式不显示**
原题库页面已在构建时改为本地 KaTeX；如果仍不显示，检查 `dist/vendor/katex/` 是否存在。
