# 单用户同步与笔记设置

更新：2026-11-17。仅供你自己在电脑和安卓等浏览器使用，不建设多用户账号系统。

## GitHub 私有进度同步

题库站点：[OS练习室](https://dou307.github.io/os-exercises/#/settings)。数据仓库：[dou307/os-exercises-progress](https://github.com/dou307/os-exercises-progress)，已实际建立并检查为私有，与你的公开题库分开。

每台设备需要完成一次连接：

1. 登录GitHub，在Settings → Developer settings → Personal access tokens → Fine-grained tokens创建令牌。
2. Resource owner选择自己，仅选择 `os-exercises-progress` 仓库；Repository permissions中的Contents选择Read and write。无需授权公开题库或其他仓库。
3. 在网站“设置与同步”填写 `dou307/os-exercises-progress`，把令牌填入本机密码输入框，勾选自动同步，点击“保存并立即同步”。不要把令牌发到聊天。
4. 另一台设备同样连接，再同步即可取得记录。令牌仅在当前标签页的sessionStorage和内存中；刷新一般保留，关闭会话后需要重新连接。

正式文件为私有仓库根目录 `progress-v1.json`。同步内容为已提交作答、收藏及取消、综合题草稿及删除、自行设置的已学章节及取消。临时未提交选项、当前页码与本机笔记目录不上传。

同步先下载并完整校验、按稳定题目ID合并，再以GitHub文件SHA条件更新；409/422最多重读重试3次。作答、收藏、草稿、已学标记采用相应修改时间决定较新记录；草稿删除及取消已学保留独立时间，防止旧备份复活。两份不同旧草稿如果均无修改时间，会停止同步并保留双方；先导出备份，再明确编辑保存希望保留的版本即可解决，不猜测哪份较新。请保持设备时间正常；两台设备同时离线作答同题时采用较新一份，不将两份次数简单相加。

启用自动同步后，本机变更等待约3秒上传；页面回到前台、网络恢复时也会同步。失败显示原因、本机保留，30秒后重试；请求30秒超时。目标公开、归档、无权限、损坏文件会被拒绝。断开会清除会话令牌并关闭自动同步，保留本机学习记录；已发出的请求可能完成。

普通备份仍可从网站导出/导入，旧v1文件兼容。浏览器清理数据会清除本机记录，尚未同步的修改不会凭空恢复。仓库Git历史会保留之前写入的学习记录。

维护验收使用独立 `acceptance-v1.json` 和隔离浏览器，不能用用户的正式记录做破坏性测试。已完成真实GitHub双浏览器上下文往返；测试文件已删除，不等于用户各设备已填写连接信息。

## Obsidian

电脑上实际注册的库名为 `Obsidian`，课程相对目录为 `1大三秋冬/OS`。在设置中分别填这两个值，保存后点击测试链接。安卓填写手机实际库名、相对目录；需要先在手机安装Obsidian并放置笔记。

链接以 `obsidian://open?vault=...&file=...` 编码库名和完整库内相对文件。原笔记只读；设置存在本机普通设置键 `os-exercises:settings:v1`。不在公开构建里硬编码绝对目录。旧 `config.local.json` 仍支持构建默认库名，但推荐页面设置以正确包含相对目录。

已核对真实库配置、16个笔记文件与URI参数。实际桌面点击验收被Computer Use URL识别安全检查中止，没有观察到Obsidian打开结果，因此这一步仍需在设备上点击确认。
