## 3. 原站的实现特点

实际检查了 HTML、样式和内联脚本：

- 纯静态 HTML/CSS，交互 JavaScript 重复内嵌于页面，没有独立应用源码工程。
- 选择题解析依靠答案文本和选项正则；遇到多空题会直接跳过。
- 原站作答记录以页面路径和题目遍历序号保存；重排题目后不适合直接沿用。
- 页面保存的是对错标记，无法完整恢复上次选错的具体选项。
- `root()` 和 `rel()` 中存在对 `kaoyan-408-os/` 路径名称的依赖；移动到其他站点子路径不能假定搜索、进度键仍然正确。
- 全站搜索依赖 `fetch(search-index.json)`；不能把双击 HTML 作为本地运行验收方式。
- 公式依赖 jsDelivr 的 KaTeX 0.16.11 CSS、主脚本和 auto-render 脚本；后续离线运行还需本地化相关字体资源。
