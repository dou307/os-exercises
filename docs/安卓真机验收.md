# 安卓真机验收

安卓可以作为本网站的手机验收设备，不要求iPhone、iPad或Mac。自动化390px和WebKit结果不能冒充真机或Safari结果。

打开[线上网站](https://dou307.github.io/os-exercises/)，使用你日常的安卓Chrome或Edge，完成以下一次检查即可。以下待用户实机执行，尚未记为通过。

- [ ] 第一章题单可滚动、题号连续；点题后编号一致。
- [ ] 提交一道答案，刷新仍保留；答错自动收藏，手动取消后刷新仍取消。
- [ ] 题卡底部跳题、上一题/下一题可点，边界禁用正确；长公式、代码表格可阅读。
- [ ] 综合题草稿输入、系统键盘弹出时能继续编辑，旋转屏幕不丢草稿。
- [ ] 导出备份能通过系统文件选择器存入本机；再导入可成功读取。
- [ ] 按[同步设置](同步与笔记设置.md)连接私有仓库：电脑收藏→手机同步出现；手机取消→电脑同步取消。
- [ ] 网络断开时仍保留当前作答；重新联网后显示同步结果。未加载资源是否可离线访问取决于浏览器缓存，本网站没有完整离线PWA安装包。
- [ ] 若手机有Obsidian，填本机库名和相对目录，点击笔记链接能打开正确文件。

记录设备型号、Android版本、浏览器版本、检查日期及失败步骤即可；不需要发送GitHub令牌。Safari专项只在需要覆盖Apple浏览器时再做。
