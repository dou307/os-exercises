# 网站审查与改进（当前版）

更新：2026-11-17。2026-10-23的完整审查见 [历史记录](history/2026-10-23-网站审查与改进.md)。

本轮完成剩余230题逐题审核及61组独立复算。结合既有530题，全库760题均有逐题归属和审核结论；新15道争议与旧37道一起停止自动计分，仍可阅读/自评。旧37道额外复审结论只在展开解析后出现。

第四章发现FAT32权限概念套用、最大文件长不能反推FAT总大小、位图兼用于主存和磁盘、题图/位宽条件缺失等；第五章发现C-SCAN与C-LOOK混用及缓冲模型前提等。完整逐题证据见相应报告。

新增单用户私有同步：先验证仓库私有并完整校验远端，再按稳定ID/修改时间合并并用SHA条件更新。取消收藏、删除草稿、取消已学不会被旧副本恢复；无远端时也保存纯删除标记。请求超时、冲突、断网、损坏文件均有保护，当前标签页令牌不进入公开构建或导出。

新增本机笔记库名和库内相对目录设置；保存后立即更新测试链接，并保留同页尚未提交的同步表单。已核对真实Obsidian配置与文件；桌面真实打开被工具URL安全检查中止，未夸大为通过。

135图完成逐张缩览并保留原始裁切记录。176年份标签分级建档，发现软硬链接引用计数题的2022标签与2009存档第31题矛盾，以及2017调度题表格的数值差异；网站给出提示，来源原文保留。

Chrome/Edge/Firefox/WebKit及390px用隔离上下文验收；真实安卓、系统文件对话框和Safari专项仍依赖对应设备。当前测试数量、发布证据与边界见 [验收报告](验收报告.md)。
